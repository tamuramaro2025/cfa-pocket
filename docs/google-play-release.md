# Google Play公開準備の中止

2026-11-12、自分専用で使う方針に変更しました。Play Consoleへの審査提出・アップロード・一般公開は行っていません。アプリ作成フォームの入力までで、ポリシーと輸出法の申告は送信していません。

登録・ログイン・認証API・アカウント削除機能を削除しました。学習記録は従来どおり端末内に保存し、JSONの書き出し・読み込みで移行できます。認証サーバーの準備やGoogle Consoleへのログインは不要です。

Androidは [Android開発・実機テスト手順](android.md) に従い、`npm run android:debug` でAPKを作って直接インストールできます。既存データを残すには同じ署名のAPKで更新してください。異なる署名への変更が必要な場合は、先にJSONを書き出しておきます。

投資を連想させるアイコン、端末内のプライバシー説明、オープンソースライセンス、Androidのセキュリティ設定は残しています。

以前用意した公開用ビルドスクリプトと専用アップロード鍵は保存していますが、現在は公開作業に使用しません。過去のDRAFT AAB・APKは登録機能を含む旧ビルドなので、今回のアプリとして使わないでください。ポリシー確認用サイトも一般公開していません。
