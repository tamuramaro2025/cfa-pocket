# 教材の範囲と補強対象

更新：2026-11-09。対象：CFA Level I。今後の受験を想定し、2027年版の科目構成・概要を基準に拡充しています。

## 今回追加した内容

- 80単元の独自学習ノートと既存220問に、LOS点検に基づく176問を追加。合計396問。
- 分野・単元あたりの固定問数をやめ、不足に応じて追加。1回の学習は最大3問のままです。
- 各単元は学習ゴール、要点、式（該当する場合）、注意点、可変数の確認問題、参照先で構成。
- [全340項目の監査結果](los-audit-2027.md) に公式PDFの位置と対応問題IDを記録しています。
- 読了・演習の着手・直近の自信あり正解を区別。公式の網羅率や習得率とは扱わない。
- 既存IDと保存キーを維持し、履歴を引き継ぐ。

## 分野ごとの拡充と残る課題

下の「扱う内容」は本アプリの独自構成で、公式LOSの翻訳・転載・一対一対応表ではありません。80単元は本アプリの数で、公式モジュール数ではありません。

| 分野 | 扱う内容の例 | 深さ・演習量の補強対象 |
|---|---|---|
| 定量分析 | リターンと指数、時間価値、確率、分布、推定、検定、回帰、データ・AI | 複雑な入出金IRR、検定統計量の選択と計算、多期間・多段階の統計ケース |
| 経済学 | 市場構造、景気、財政、金融、地政学、貿易、為替表示・平価 | 市場構造別の数値分析、政策の複合ケース、複数通貨の売買スプレッド |
| 財務諸表分析 | 報告書、BS、CF、在庫、長期資産、リース・年金、税、品質・予測 | 複雑な希薄化EPS、制度差の計算、CF直接法への変換、統合予測モデル |
| 株式投資 | 権利、取引、株主還元、DCF、倍率、予測、競争、調査・因子 | 多段階成長の反復計算、複雑なモデル、企業別ケースと感応度分析 |
| 債券 | 契約、資金調達、評価、利回り、曲線、金利リスク、信用、証券化 | 利払日間の評価、複数スプレッド、複雑なCF・証券化トランシェの計算 |
| 倫理・職業行為基準 | 判断の枠組み、専門職、市場、顧客、雇用主、分析、相反、試験・称号 | 基準ごとの例外と複合事例。GIPSの要点は補助学習として収録 |
| 企業財務 | 法人と所有、統治、流動性、投資、柔軟性、資本構成、事業、固定費 | 資本配分の複合ケース、資金制約、法域差。レバレッジ単元は基礎補助を含む |
| ポートフォリオ構築 | 効用、フロンティア、CAPM、IPS、配分、行動、リスク、成果評価 | 効率的配分の数値問題、投資家ケース、リスク指標の統合判断 |
| デリバティブ・リスク管理 | 市場と裁定、先渡、先物、スワップ、オプション、パリティ、二項、ヘッジ | 配当等を含む価格計算、複数支払の評価、複数期モデル |
| オルタナティブ投資 | 構造、成果測定、PE、デット、不動産、インフラ、商品、ヘッジ・デジタル | 複雑な報酬ウォーターフォール、CF測定、個別戦略の詳しい比較 |

## 確認範囲

公式2027アウトライン全31ページの340項目を位置ごとに確認し、各項目と実在する問題IDを対応付けました。すべてに少なくとも部分的な関連演習があり、計算等の要求を明示する56項目には数値演習を記録しています。ただし複合LOSの全動詞・条件・例外の充足まで確認したものではなく、完全網羅とは判定していません。Practical Skills Modulesと2026年用の差分教材は対象外。出題比率に合わせた模試も未実装です。

単元の確認問題数は内容に応じて異なります。一つの関連問題で単元やLOS全体の習得を判定しません。専門家監修、年度ごとの改訂確認、実戦難度の演習量は引き続き補強対象です。
